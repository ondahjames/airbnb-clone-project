# airbnb-clone-project
A clone of the AirBnB web app built using modern web technologies

---

## Overview
The AirBnB Clone Project is a web application that replicates core features of the AirBnB platform — including user authentication, property listings, and booking functionality.

This project aims to strengthen skills in full-stack web development, focusing on clean architecture, collaboration, and version control with Git and GitHub.

## Project Goals
- Build a scalable backend and responsive frontend
- Implement CRUD operations for listings and users
- Practice team collaboration using Git and GitHub
- Deploy a functional web application to the cloud

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript (React or Vue optional)
- **Backend:** Python (Flask/Django) or Node.js (Express)
- **Database:** MySQL or MongoDB
- **Version Control:** Git & GitHub
- **Deployment:** AWS / Render / Vercel
